Campus Jobs API Documentation

Базовый URL: /api

GET /api/vacancies

Получить список вакансий.

GET /api/vacancies/{id}

Получить карточку вакансии.

POST /api/vacancies/{id}/apply

Отправить отклик.

{
  "student_email": "student@example.com",
  "student_full_name": "Иван Иванов",
  "faculty": "ФКН",
  "study_year": 3,
  "cover_letter": "Минимум 30 символов..."
}

GET /api/applications?student_email=...

Получить отклики студента.

{
  "error_code": "VALIDATION_ERROR",
