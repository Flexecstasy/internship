# Campus Jobs — сервис поиска временной работы и стажировок

Демо-проект под кейс университета: студенты находят вакансии, открывают карточку, отправляют отклик и отслеживают статус.

## Что реализовано

- Ключевой пользовательский сценарий (front + back):
  1. Главная страница со списком вакансий.
  2. Переход в карточку вакансии.
  3. Отправка отклика.
  4. Переход в «Мои отклики» и просмотр статусов.
- Адаптивная верстка (desktop + mobile) на Bootstrap.
- API на Python (WSGI) с документацией: `/docs`.
- Детализированная обработка ошибок (валидация, не найдено, бизнес-ограничения, серверные ошибки).
- Архитектура БД с визуализацией (11 сущностей): `docs/db_architecture.md`.

## Запуск

```bash
python -m app.server
```

Открыть:
- Web UI: `http://127.0.0.1:8000/`
- API docs: `http://127.0.0.1:8000/docs`

## Примеры ошибок API

### 1) Некорректные данные (422)
Если `study_year` вне диапазона 1..6 или короткое `cover_letter`, API вернет список полей с проблемами.

### 2) Вакансия не найдена (404)
`GET /api/vacancies/9999` вернет:
- `error_code: VACANCY_NOT_FOUND`
- человеко-понятное `user_message`
- тех. `developer_message`
- `suggestion`, как исправить

### 3) Дубликат отклика (400)
Повторный отклик студента на ту же вакансию вернет:
- `error_code: DUPLICATE_APPLICATION`
- id существующей заявки в `details`
